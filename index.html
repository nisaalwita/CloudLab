BAGIAN 1

Kenali dunia cloud

Baca singkat · pahami konsep

Apa itu cloud computing?

Cloud computing adalah cara menyediakan sumber daya komputasi—seperti server, penyimpanan, jaringan, platform, dan aplikasi—melalui jaringan sesuai kebutuhan. Pengguna dapat memakai sumber daya tersebut tanpa harus mengelola seluruh perangkat fisik di lokasi sendiri.

Contoh dekat: sekolah menggunakan penyimpanan daring untuk berbagi dokumen. File disimpan pada infrastruktur penyedia layanan dan dapat diakses melalui internet sesuai hak akses pengguna.

Inti konsep: cloud bukan sekadar “komputer yang ada di internet”. Cloud menggabungkan sumber daya komputasi, akses jaringan, pengelolaan, dan penyediaan layanan yang fleksibel.

Lima karakteristik penting

  1. On-demand self-service: pengguna dapat menyediakan sumber daya saat diperlukan.
  2. Broad network access: layanan dapat diakses melalui jaringan dari berbagai perangkat.
  3. Resource pooling: sumber daya penyedia digunakan bersama dan dialokasikan secara dinamis.
  4. Rapid elasticity: kapasitas dapat ditambah atau dikurangi sesuai kebutuhan.
  5. Measured service: penggunaan sumber daya dapat dipantau dan diukur.

Kenapa organisasi memakai cloud?

  • Mengurangi kebutuhan membeli semua server sejak awal.
  • Mempercepat penyediaan lingkungan kerja atau aplikasi.
  • Menyesuaikan kapasitas dengan beban penggunaan.
  • Mendukung akses dan kolaborasi dari lokasi berbeda.

Cloud tetap memerlukan perencanaan biaya, keamanan, koneksi, backup, dan pengelolaan.

MODEL LAYANAN

IaaS, PaaS, atau SaaS?

IaaS

Infrastructure as a Service

Penyedia memberi sumber daya dasar seperti mesin virtual, jaringan, dan storage. Pengguna masih mengelola OS, aplikasi, dan konfigurasi di dalam VM.

Contoh: menyewa VM untuk memasang Linux dan web server.

PaaS

Platform as a Service

Penyedia menyiapkan platform untuk menjalankan aplikasi. Pengguna fokus pada kode dan data, sementara banyak pengelolaan server dan runtime ditangani penyedia.

Contoh: platform hosting aplikasi yang mengelola runtime.

SaaS

Software as a Service

Pengguna langsung memakai aplikasi siap pakai melalui web atau aplikasi. Infrastruktur dan platform dikelola penyedia.

Contoh: email web atau aplikasi dokumen kolaboratif.

Cara cepat membedakan: IaaS memberi fondasi infrastruktur, PaaS memberi lingkungan untuk membangun/menjalankan aplikasi, sedangkan SaaS memberi aplikasi yang siap digunakan.
MODEL PENERAPAN

Di mana cloud ditempatkan?

Public cloud

Infrastruktur disediakan penyedia layanan untuk banyak pelanggan. Sumber daya tiap pelanggan dipisahkan secara logis.

Private cloud

Lingkungan cloud digunakan khusus oleh satu organisasi. Pengelolaannya dapat dilakukan sendiri atau oleh pihak lain.

Hybrid cloud

Menggabungkan dua atau lebih lingkungan berbeda—misalnya private dan public—yang saling terhubung untuk kebutuhan tertentu.

Community cloud

Infrastruktur digunakan bersama oleh beberapa organisasi yang memiliki kebutuhan atau kebijakan sejenis.

VIRTUALISASI

Satu server fisik, beberapa server virtual

Virtualisasi memungkinkan satu komputer fisik menjalankan beberapa lingkungan komputasi terpisah. Setiap virtual machine (VM) memiliki sistem operasi dan sumber daya virtual sendiri, meskipun CPU, RAM, storage, dan perangkat fisiknya berasal dari host yang sama.

Hypervisor adalah lapisan perangkat lunak yang membuat dan mengelola VM. Proxmox Virtual Environment (Proxmox VE) adalah platform manajemen virtualisasi berbasis web yang menggunakan KVM untuk VM dan LXC untuk container.

VM dan container

VM: menjalankan OS guest sendiri melalui virtual hardware. Cocok saat butuh isolasi OS yang lebih lengkap atau kernel berbeda.

Container: mengisolasi aplikasi dan dependensinya, tetapi berbagi kernel host. Umumnya lebih ringan untuk layanan yang sesuai.

Komponen Proxmox yang perlu dikenal

  • Node: host/server Proxmox.
  • VM ID: identitas mesin virtual.
  • Storage: lokasi disk VM, ISO, backup, dan data.
  • Bridge (vmbr0): penghubung jaringan virtual ke jaringan fisik atau segmen virtual.
  • Snapshot: titik kondisi VM pada waktu tertentu untuk kebutuhan pemulihan/ujicoba.

MISI KAMU SEBAGAI TEKNISI

Bangun satu server layanan untuk sekolah

Sekolah membutuhkan server untuk menjalankan website internal. Tugasmu adalah memilih jenis lingkungan, membagi sumber daya host, dan menentukan bagaimana komputer di laboratorium dapat menjangkau server tersebut.

Langkah 1 · RencanakanTentukan layanan dan kebutuhan CPU, RAM, serta disk.
Langkah 2 · HubungkanPilih bridge agar VM dapat terhubung ke LAN, atau jaringan terisolasi untuk latihan internal.
Langkah 3 · KelolaJalankan VM, simpan snapshot, dan pelajari pemulihannya.
Tujuan lab: setelah selesai, kamu dapat menjelaskan mengapa satu server fisik bisa menjalankan beberapa server virtual, mengapa kapasitas host harus diperhitungkan, dan bagaimana VM dihubungkan ke jaringan.

Rancang kebutuhan server

Pilih layanan yang akan dijalankan. Nilai CPU, RAM, dan disk yang kamu pilih akan diambil dari kapasitas host di sebelah kanan.
